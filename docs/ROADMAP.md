# Roadmap

The starter includes category browsing, media dialogs, local and optional Mux playback, photo navigation, structured profiles, case study examples, and a procedural 3D demo.

Possible contributions:

- Additional generic case study layouts.
- Optional CMS adapters with documented setup.
- More keyboard, assistive technology, and browser coverage.
- Automated responsive screenshot comparisons.

Keep example content generic. Do not contribute personal media, credentials, live account identifiers, or unsupported claims.
